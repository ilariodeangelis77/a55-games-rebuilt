Box Pusher

Push every box onto a marked spot. The engine is a rebuild of the decompiled firmware; levels and tiles are extracted from your dump.

Controls

2468 or arrows
Move
Q Backspace F1
Undo (left soft key)
W F2
Restart the level (right soft key)
Enter 5
OK / select
* numpad
Sound on/off
Esc
End: leave the game, then back to the Games menu

Every key can be remapped under Controls in the port menu; Level picks where to start. Opened from the Games menu, the page starts on the phone's original start screen.
